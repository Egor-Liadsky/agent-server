# AGENTS.md

`agent-sever` — независимый Rust-сервис `agentd` на axum и SQLite через sqlx.

- Общение — на русском языке; код, команды, ошибки и commit messages — на
  английском. Документация и комментарии — на русском.
- Выполнять команды из `agent-sever`, не из зонтичного каталога.
- Конфигурация сервиса задаётся переменными `AGENTD_*`; клиентский конфиг не
  читать и не подменять им настройки сервиса.
- При изменении контракта или поведения обновлять README. Skills для Codex
  находятся в `.agents/skills/`, Claude-версии сохранены в `.claude/skills/`.
- Общая проверка: `cargo test`; для финальной проверки зависимостей —
  `cargo test --locked`.
- Если затронуто `agentcore`, соблюдать порядок из корневого `AGENTS.md`:
  сначала тесты и публикация `agent-cli`, затем lock-файл и тесты сервиса.
- Не удалять и не перезаписывать `.claude/` при работе с Codex.
